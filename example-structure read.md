# Technical Heartbeat: IoT and Cold-Chain Data in North Kivu

## Overview
This project documents how we built a telemetry and alert system for food sovereignty in conflict-affected zones.

## Architecture
- Marine Node (Sonar + GPS)
- Smart Charcuterie (Bio-environmental sensors)
- Last-Mile Bridge (Fiber-optic hubs)
